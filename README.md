# Веб-сайт "Кастом столов"
Краткое описание

Наш веб-сайт это веб-приложение для проектирования индивидуальных столов. Пользователи могут создавать уникальные дизайны, изменяя размеры, добавляя декоративные элементы через.

Технологии

Frontend:
HTML5 — семантическая разметка и структура приложения
CSS3 — стилизация, адаптивный дизайн, анимации
JavaScript (ES6+) — логика приложения и интерактивность
LocalStorage API — хранение пользовательских данных
Drag-and-drop API — интуитивное управление элементами

Запуск проекта

Требования:
Любой современный браузер (Chrome 80+, Firefox 75+, Safari 14+, Edge 80+)
Доступ к интернету (только для первоначальной загрузки)

Установка и запуск:

Локальный запуск (самый простой)
1. Скачайте архив проекта
2. Распакуйте в любую папку
3. Откройте файл index.html в браузере

Дальнейшее развитие

1. Расширение библиотеки элементов 
   - Добавление 20+ новых стикеров и рамок
   - Тематические наборы (природа, космос, геометрия)
   - Загрузка пользовательских изображений

2. Улучшение функционала
